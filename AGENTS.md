## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `uncertaintea-io/weewoo`. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage labels use the default Matt Pocock skills vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

This repo uses the single-context domain docs layout. See `docs/agents/domain.md`.

### Pull request review threads

Do not resolve GitHub pull request review threads unless the user explicitly asks for them to be resolved. When addressing or responding to review feedback, leave the threads open for manual review by default.
